# 4-Layer Ethernet PCB Design – Cadence Allegro

## 📌 Overview

This project focuses on designing a **4-Layer Ethernet PCB from scratch using Cadence Allegro PCB Designer.**

The design process includes schematic creation, custom footprint development using IPC-7351 guidelines, and PCB layout implementation based on IPC-2221 design guidelines.

The objective is to gain practical experience in professional PCB design, component placement, routing, design constraints, and PCB verification.

## 🛠 Tools & Standards Used

- Cadence Allegro PCB Designer (Schematic & PCB Layout)
- IPC-7351 – Component Footprint and Land Pattern Guidelines
- IPC-2221 – Generic PCB Design Guidelines

## ⚡ Design Description

- **PCB COUNT:** 4-Layer. 
- **PCB Thickness:** 1.6 MM. 
- **Layer Stackup:** Top Signal, Ground, Power, and Bottom Signal.
- **Footprint Creation:** Custom footprint development based on IPC-7351 and manufacturer datasheets.
- **PCB Layout:** Component placement, routing, clearance, and spacing based on IPC-2221 guidelines.

## 🚀 🔧 Features

1. Complete schematic design from scratch.
2. Custom footprint creation using IPC-7351 guidelines.
3. 4-layer PCB stackup configuration.
4. Ethernet connector integration.
5. Component placement and PCB routing.
6. Design constraints based on IPC-2221 guidelines.
7. Design Rule Check (DRC) verification.
8. 3D PCB visualization and DFM file generation.
